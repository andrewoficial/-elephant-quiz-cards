# Roadmap

## MVP (в порядке реализации)

1. **Foundation** — модули, DI (Koin), БД, навигация. ✅
   - Модули ✅, БД (SQLDelight) ✅, DI (Koin) ✅, навигация ✅ (ручной роутер, ADR-003).
2. **Domain** — `TopicNode`, `Card`, `ReviewLog` + репозитории. ✅ (модели, SM-2,
   критерий «выучено», `SqlDelightStore`).
3. **Tree UI** — экран subjects (аккордеон + прогресс-бары). ✅ (базово, на реальных данных;
   детализация по §6 позже).
4. **Editor** — CRUD карточек, поиск, 3 вкладки. 🚧 (CRUD + поиск ✅; вкладки/импорт ⏳).
5. **Training** — 4 метода + SM-2 + очередь на сегодня. ✅ (бэкенд: `ReviewLogRepository`,
   `TrainingScheduler`, журнал + SM-2; экраны `jungle/{areaId}` и `training/{areaId}/{mode}`;
   все 4 метода: **Самоконтроль**, **Открытый вопрос**, **Варианты ответа** (всё-или-ничего),
   **Ввод по буквам** (посимвольно, 3 жизни); показ случайного варианта вопроса).
   Осталось: учёт `variantId`/`timeSpentMs` в логе.
6. **Progress** — критерий «выучено», агрегация по дереву. ✅ (домен `isLearned`/`learnedRatio`
   по §4; UI дерева (`subjects`) использует доменный критерий для областей и дисциплин —
   вместо прежнего упрощённого `intervalDays ≥ 20`).
7. **Import/Export** — JSON по §5.2/§5.3. ⏳
8. **Demo deck** — Java-колода. ⏳
9. **Drive sync** — OAuth + синк. ⏳
10. **DeepSeek** — 2 навыка из §7. ⏳

## Post-MVP
GitHub-публикация, чат с ИИ, режим собеседования, медиа, уведомления,
код-ответы, iOS.
